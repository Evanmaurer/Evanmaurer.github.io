# Evan Maurer — Portfolio

Live site: **https://evanmaurer.github.io/**

## Run locally

```bash
cd ~/evan-maurer-portfolio
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Publishes `dist/` to the `gh-pages` branch of `Evanmaurer/Evanmaurer.github.io`.
